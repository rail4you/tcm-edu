## 5. 技术架构（实际）

```
┌──────────────────────────────────────────────────────────────┐
│  接入层  Nginx/Caddy (TLS) → :80/443                          │
├──────────────────────────────────────────────────────────────┤
│  前端  Next.js 16 (React 19)                                  │
│    ├─ 学员端  /  /courses  /course  /learn  /my-learning     │
│    ├─ 教师端  /teacher/*                                      │
│    ├─ 管理端  /admin/*                                        │
│    └─ 公开页  /login /about                                   │
│    构建: 静态导出 → priv/app/  (Phoenix 部署)                │
├──────────────────────────────────────────────────────────────┤
│  后端  Phoenix 1.8 (Elixir 1.18, OTP 27)                      │
│    ├─ /api/*  RPC  (AshTypescript.Rpc)                        │
│    ├─ /admin-dashboard  LiveView (Antd)                       │
│    ├─ Ash Authentication (password + tokens)                  │
│    ├─ Jido AI Agents (导师/批改/分析)                         │
│    └─ Oban 后台任务 (组卷/出题/出证)                          │
├──────────────────────────────────────────────────────────────┤
│  数据层  PostgreSQL 13+                                       │
│    ├─ public  (超管 / tokens / 租户目录)                     │
│    ├─ tenant_default (默认租户, 演示数据)                    │
│    └─ tenant_<slug> (每租户独立 schema)                       │
├──────────────────────────────────────────────────────────────┤
│  AI 服务  阿里云百炼 API（阶段一）                            │
│    ├─ 通义千问 Qwen (文本对话 + 多模态)                       │
│    ├─ DeepSeek V4 (推理)                                     │
│    └─ 阶段二 + Qwen Omni Realtime / CosyVoice / Wan          │
├──────────────────────────────────────────────────────────────┤
│  存储  本地 FS (阶段一) → S3/OSS (阶段二生产)                │
├──────────────────────────────────────────────────────────────┤
│  部署  Docker (单一 release, 多租户共享集群)                  │
└──────────────────────────────────────────────────────────────┘
```

**与合同原文的对应关系**：
- 合同 §1.6.1「七层分布式架构」→ 实际简化为「前端 + 后端 + DB + AI + 存储」五层，因单体 Phoenix + Postgres 完全可承载百级租户/万级用户，分布式架构留作后续演进（合同未限定并发指标）。
- 合同 §1.6.6「Docker 容器化」→ ✅ 已有。
